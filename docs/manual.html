Sextant field manual

A local reference for the model language and CLI. Open this file directly; it has no scripts, no external resources and no network calls.

Commands

CommandPurpose
check <machine>Structural verification of states, events, guards and reachability.
replay <machine> <events>Deterministic trace of every transition.
golden <machine> <events> <file>Compare a trace with a committed golden file.
explore <machine>Bounded enumeration of reachable configurations.
generate <machine> --seed NReproducible event script from a pure PRNG.

Machine statements

FormMeaning
machine nameNames the model.
initial stateSets the start state.
state nameDeclares a state.
event nameDeclares an event.
transition from event [when cond] [do effects] -> toDefines one edge.
invariant name: condA condition that must always hold.

Example

machine retry
initial idle
state idle
state waiting
state done
event START
event TICK
event OK
event RESET
transition idle START -> waiting
transition waiting TICK when tries <= 2 do tries += 1 -> waiting
transition waiting OK -> done
transition done RESET do tries = 0 -> idle
invariant tries_bound: tries <= 3

Exit codes: zero for success, one for a verification failure, two for a usage error. Data commands write only data to standard output; human status goes to standard error.
